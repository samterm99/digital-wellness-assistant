# ผู้ช่วยสุขภาพดิจิทัล (ต้นแบบ Windows)

โปรแกรมเล็ก ๆ อยู่ในถาดระบบ (ข้างนาฬิกา) คอยเตือนให้ **พักสายตา**, **ลุกขึ้นเดิน**, **ปรับท่านั่ง**
การแจ้งเตือนเป็นข้อความเล็ก ๆ มุมขวาล่างของ Windows (ไม่มีหน้าต่างใหญ่หรือป๊อปอัปทับหน้าจอ)
ไม่ต้องใช้อินเทอร์เน็ต ไม่ต้องติดตั้งอะไรเพิ่ม (ใช้ Python ที่มีอยู่ในเครื่อง)

## เปิด / ปิดโปรแกรม (ไม่ต้องใช้ Claude Code)
| ต้องการ | ดับเบิลคลิกไฟล์ |
|---|---|
| **เปิดโปรแกรม** | `start.bat` (จะเปิดไอคอนในถาดระบบ + หน้าต่างควบคุม) |
| **ปิดโปรแกรม** | `stop.bat` หรือคลิกไอคอน → "ปิดโปรแกรม" |
| ตรวจการตรวจจับเต็มจอ | `check_fullscreen.bat` |
| รันชุดทดสอบอัตโนมัติ | `run_tests.bat` |

ดับเบิลคลิก `start.bat` ซ้ำได้ ไม่เกิดโปรแกรมซ้อน

## หน้าต่างควบคุม
เปิดจาก `start.bat`, หรือดับเบิลคลิกไอคอนในถาดระบบ, หรือคลิกไอคอน → "เปิดหน้าต่างควบคุม"
- แสดงสถานะ: **● กำลังทำงาน** / **⏸ หยุดชั่วคราว** / **○ โปรแกรมไม่ได้ทำงาน**
- แสดง **เวลานับถอยหลัง** ของแต่ละการเตือน (เช่น "เตือนอีก 12:34")
- ปุ่มหยุดชั่วคราว / เริ่มต่อ / หยุด 30 นาที / หยุด 1 ชั่วโมง / ทดสอบแจ้งเตือน
- ตั้งเวลา (นาที) ของแต่ละการเตือน เปิด-ปิดแต่ละอย่าง แล้วกด **บันทึกการตั้งค่า** (มีผลทันที)
- ปิดหน้าต่างนี้ได้เลย โปรแกรมเตือนยังทำงานต่อที่ถาดระบบ

ค่าเริ่มต้น: พักสายตาทุก 20 นาที, ปรับท่านั่งทุก 30 นาที, ลุกเดินทุก 45 นาที

## เมนูคลิกที่ไอคอน
เปิดหน้าต่างควบคุม · หยุด/เริ่มต่อ · หยุด 30 นาที / 1 ชั่วโมง · เริ่มพักสายตา 20 วินาที · ทดสอบการแจ้งเตือน · ปิดโปรแกรม

## พฤติกรรมที่ควรรู้
- **หยุดแล้วเริ่มต่อ:** นับเวลาใหม่ทั้งหมด (ไม่มีแจ้งเตือนเด้งทันที)
- **ใช้งานเต็มจอ** (ดูหนัง/เกม/นำเสนอ): ไม่เด้งแจ้งเตือน และจะแสดงหลังออกจากเต็มจอ
- **ล็อกหน้าจอ / เครื่องหลับ:** ถือว่าคุณได้พักแล้ว กลับมาแล้วนับเวลาใหม่ (ไม่เด้งรัว ๆ)
- **ถ้าไม่เห็นแจ้งเตือน:** ตรวจ "ห้ามรบกวน" / Focus Assist ของ Windows (ตั้งค่า → ระบบ → การแจ้งเตือน)
- **ปัญหาที่ไม่ทราบสาเหตุ:** ดูบันทึกการทำงานที่ `logs\app.log`
- **เปิดอัตโนมัติตอนล็อกอิน Windows:** ผ่านทางลัดในโฟลเดอร์ Startup ที่ชี้ไป `start.bat` (ตัวโปรแกรมไม่แก้ Registry/Task Scheduler)
  - ติ๊ก **"แสดงหน้าต่างควบคุมเมื่อเริ่ม Windows"** (ค่าเริ่มต้น เปิด) เพื่อเลือกว่าตอนล็อกอินจะเปิดหน้าต่างควบคุมด้วยหรือไม่
    ถ้าปิด จะเหลือเพียงไอคอนถาดระบบ มีผลในการล็อกอินครั้งถัดไป โดยไม่ต้องแก้ทางลัด
  - `start.bat startup` = เริ่มตอนล็อกอิน (ทำตามตัวเลือกนี้แน่นอน), `start.bat` เฉย ๆ = เปิดด้วยมือ ถ้าทางลัด Startup ยังไม่ใส่คำว่า `startup` ในช่อง "อาร์กิวเมนต์" โปรแกรมจะเดาจากเวลาที่ Windows เริ่มเดสก์ท็อป (<2 นาที) ซึ่งการเปิดด้วยมือช่วงนั้นอาจไม่เห็นหน้าต่าง ให้ดับเบิลคลิกไอคอนถาดแทน
  - ป้องกันโปรแกรมซ้อนเหมือนเดิม
- **พักสายตา 20 วินาที:** ถึงเวลาพักสายตา จะมีหน้าต่างเล็ก "ถึงเวลาพักสายตา" เด้งขึ้นมุมขวาล่างเอง (เหนือแถบงาน) แทนการแจ้งเตือนของ Windows
  - กด **เริ่มพัก 20 วินาที** จึงจะเริ่มนับถอยหลัง (ไม่ต้องมองหน้าต่าง ให้มองไกลประมาณ 6 เมตร) ครบแล้วมีเสียงเบา ๆ หนึ่งครั้ง (ถ้าเปิดเสียงไว้) และหน้าต่างปิดเอง
  - กด **ข้าม** หรือกากบาท = ปิดทันทีแบบเงียบ · ถ้าไม่ตอบใน 15 วินาที หน้าต่างปิดเอง · ไม่เลื่อนเตือน รอรอบปกติถัดไป
  - ระหว่างนับ กด **ยกเลิก** หรือกากบาทได้ (ไม่มีเสียง) · หน้าต่างไม่แย่งโฟกัสแป้นพิมพ์ · เปิดซ้อนไม่ได้
  - ไม่ขึ้นเองตอนหยุดชั่วคราว หรือตอนใช้งานเต็มจอ (ถ้าติ๊ก "ไม่แจ้งเตือนตอนใช้งานเต็มจอ")
  - เปิดด้วยมือ: ไอคอนถาดระบบ → "เริ่มพักสายตา 20 วินาที" หรือปุ่มในหน้าต่างควบคุม จะเห็นหน้าต่างเดียวกัน รอให้กดเริ่มเอง และไม่ปิดเองใน 15 วินาที
  - ท่านั่งและลุกเดิน ยังใช้การแจ้งเตือนของ Windows เหมือนเดิม
  - ถ้าเตือนหลายอย่างถึงเวลาพร้อมกัน จะแสดงทีละอย่าง เรียงตามอันที่เลยกำหนดนานที่สุดก่อน ห่างกันอย่างน้อย 60 วินาที (ตั้งช่วงสั้นกว่า 2 นาทีหลายอย่างพร้อมกัน ช่วงจริงอาจยืดเป็นสลับกัน)
  - ข้อจำกัด: ชื่อผู้ส่งแจ้งเตือน Windows ยังแสดงเป็น "Python" (ต้องแก้ตอนทำตัวติดตั้ง และต้องทดสอบหลังติดตั้ง)
  - ปิดเสียง: เอาติ๊ก "เล่นเสียงเบา ๆ เมื่อครบเวลาพักสายตา 20 วินาที" ออก แล้วกดบันทึกการตั้งค่า
- **ระยะเวลาแสดงแจ้งเตือน:** Windows เป็นผู้กำหนดเอง (ตั้งค่า → การช่วยการเข้าถึง → การแจ้งเตือนภาพ → "แสดงการแจ้งเตือนเป็นเวลา") โปรแกรมกำหนดเวลาแน่นอนไม่ได้
- **ยังไม่มี (เลื่อนไปเวอร์ชันหน้า):** แจ้งเตือนที่ค้างจนกว่าผู้ใช้กดรับทราบ เพราะแจ้งเตือนแบบที่ใช้อยู่ไม่รองรับอย่างเชื่อถือได้

## ช่วยทดสอบเต็มจอจริง (YouTube / Netflix) — ใช้เวลา 2 นาที
1. ดับเบิลคลิก `check_fullscreen.bat` (บันทึก 90 วินาที)
2. ระหว่างนั้นเปิด YouTube เต็มจอ ~15 วินาที ออกจากเต็มจอ แล้วเปิด Netflix เต็มจอ ~15 วินาที
3. เปิดไฟล์ `logs\diag.txt` ถ้าเห็น `BUSY(fullscreen)` ตอนเต็มจอ แปลว่าตรวจจับได้
   (ไฟล์เก็บเฉพาะ "สถานะ" และ "ชนิดหน้าต่าง" ไม่เก็บชื่อวิดีโอหรือเนื้อหา)

## ติดตั้งแบบสคริปต์ (ใช้ได้ทุกเครื่อง รวม Windows 11 ที่เปิด Smart App Control)
ไฟล์ `DigitalWellnessAssistant-Script-1.2.1.zip` (ในหน้า Releases) — ไม่มีไฟล์ .exe ของเรา ใช้ Python ตัวจริงรันซอร์สโค้ดโดยตรง
1. แตกไฟล์ zip (คลิกขวา → Extract All) แล้วดับเบิลคลิก `INSTALL.bat`
2. ถ้าเครื่องไม่มี Python 3.9+ ที่มี tkinter ตัวติดตั้งจะติดตั้ง Python 3.12 ให้ผ่าน winget
3. ตอบ Y/N เรื่องเปิดอัตโนมัติตอนเข้า Windows → ไอคอนอยู่ที่ถาดระบบ
- ติดตั้งที่ `%LOCALAPPDATA%\DigitalWellnessAssistant-Source` (ตั้งค่าและบันทึกอยู่ในโฟลเดอร์เดียวกัน) · ถอนการติดตั้งด้วย `UNINSTALL.bat`
- **แอนตี้ไวรัสอื่น (เช่น 360 Total Security):** ระหว่างติดตั้ง Python อาจมีหน้าต่างเตือนพร้อมนับถอยหลังประมาณ 10 วินาที ให้กด "Allow" ให้ทัน ถ้าไม่ทันจะติดตั้งไม่สำเร็จ ให้รัน `INSTALL.bat` ใหม่
- ไม่ต้องปิดระบบความปลอดภัยของ Windows ใดๆ

### เลือกแบบไหนดี
เปิด Windows Security → App & browser control → Smart App Control
| สถานะ | แนะนำ |
|---|---|
| ไม่มีหัวข้อนี้ (Windows 10) หรือเป็น **Off** | ใช้ตัวติดตั้ง `.exe` หรือแบบสคริปต์ก็ได้ |
| **On** หรือ **Evaluation** | ใช้แบบสคริปต์เท่านั้น (Smart App Control บล็อก .exe ที่ไม่ได้ลงลายเซ็น) |

อย่าปิด Smart App Control เพื่อติดตั้งโปรแกรมนี้ — ปิดแล้วเปิดกลับอาจทำไม่ได้ในบางเวอร์ชันของ Windows

## ติดตั้งบน Windows (ตัวติดตั้ง .exe v1.2.0)
ไฟล์ `DigitalWellnessAssistant-Setup-1.2.0.exe` — Windows 10/11 64 บิต ไม่ต้องมี Python ไม่ต้องใช้สิทธิ์ผู้ดูแล (ถ้า Windows 11 เปิด Smart App Control ให้ใช้แบบสคริปต์ด้านบนแทน)
- **ติดตั้ง:** ดับเบิลคลิกไฟล์ → Next → ตัวเลือก "เปิดผู้ช่วยสุขภาพดิจิทัลอัตโนมัติเมื่อเข้าสู่ Windows" (ติ๊กไว้ให้) → Install → ติดตั้งที่ `%LOCALAPPDATA%\Programs\DigitalWellnessAssistant` พร้อมทางลัดในเมนู Start
  (Windows SmartScreen อาจเตือนเพราะไฟล์ยังไม่ได้เซ็นลายเซ็นดิจิทัล — เลือก "More info → Run anyway")
- **เปิดครั้งแรก:** เมนู Start → "ผู้ช่วยสุขภาพดิจิทัล" (หรือติ๊กเปิดทันทีตอนจบการติดตั้ง) จะเห็นหน้าต่างควบคุมและไอคอนในถาดระบบ
- **เริ่มพร้อม Windows กับหน้าต่างควบคุม แยกกัน:** ตัวติดตั้งสร้างทางลัดใน Startup ให้ (`--launch --startup`) ถ้าไม่ติ๊ก หรือไม่ต้องการ ให้ลบทางลัด "ผู้ช่วยสุขภาพดิจิทัล" ในโฟลเดอร์ Startup
  ส่วนจะให้หน้าต่างควบคุมเด้งตอนเริ่ม Windows หรือไม่ ใช้ตัวเลือกเดิมในหน้าต่างควบคุม "แสดงหน้าต่างควบคุมเมื่อเริ่ม Windows"
- **ข้อมูลผู้ใช้:** ตั้งค่า สถานะ และบันทึก อยู่ที่ `%LOCALAPPDATA%\DigitalWellnessAssistant` (ไม่อยู่ในโฟลเดอร์โปรแกรม) ตัวติดตั้งไม่นำเข้าค่าจากเครื่องพัฒนา
- **อัปเกรด:** รันตัวติดตั้งรุ่นใหม่ทับได้เลย โปรแกรมเก่าถูกปิดให้เอง การตั้งค่าและช่วงเวลาเตือนเดิมไม่ถูกแตะ
- **ถอนการติดตั้ง:** Settings → Apps → "ผู้ช่วยสุขภาพดิจิทัล" → Uninstall จะถามว่าลบการตั้งค่าและบันทึกด้วยหรือไม่ (ค่าเริ่มต้น = เก็บไว้) ทางลัด Start/Startup ถูกลบ
- **ชื่อผู้ส่งแจ้งเตือน:** exe ตั้ง AppUserModelID `DigitalWellness.Assistant` และตัวติดตั้งลงทะเบียนชื่อแสดงผลภาษาไทยที่ HKCU (ถอนการติดตั้งแล้วลบออก) — ต้องตรวจบนเครื่องที่ติดตั้งจริง
- **ข้อจำกัด:** ไฟล์ติดตั้งยังไม่ลงลายเซ็นดิจิทัล · ยังไม่มีไอคอนโปรแกรมเฉพาะ (ใช้ไอคอนมาตรฐาน) · อย่าติดตั้งทับขณะรันเวอร์ชันพัฒนา (start.bat) อยู่ เพราะใช้ชื่อ single-instance เดียวกัน ให้รัน `stop.bat` ก่อน

## สร้างตัวติดตั้ง (สำหรับผู้พัฒนา)
`powershell -File packaging\build.ps1` — สร้างทุกอย่างนอกโฟลเดอร์ซอร์ส (ค่าเริ่มต้น `%USERPROFILE%\DWA-build`)
1. PyInstaller (ติดตั้งใน venv ของโฟลเดอร์ build เอง) → `dist\DigitalWellnessAssistant\` (onedir, ไม่มีหน้าต่างคอนโซล, เมทาดาทาจาก `packaging\version_info.txt`)
2. Inno Setup 6 (`ISCC.exe` จากโฟลเดอร์ build, `%LOCALAPPDATA%\Programs\Inno Setup 6` หรือ Program Files) + `packaging\installer.iss` → `installer\DigitalWellnessAssistant-Setup-<รุ่น>.exe`
เปลี่ยนเลขรุ่นที่ `installer.iss`, `version_info.txt` — exe เดียวทำทุกโหมด (`--launch`, `--panel`, `--eyebreak`, `--quit`, ไม่มี flag = ถาดระบบ)
