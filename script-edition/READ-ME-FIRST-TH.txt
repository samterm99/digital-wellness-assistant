ผู้ช่วยสุขภาพดิจิทัล (Digital Wellness Assistant) - ชุดติดตั้งแบบสคริปต์ v1.2.1 (โปรแกรม v1.2.0)
===========================================================================================

โปรแกรมนี้ช่วยเตือนพักสายตา (กฎ 20-20-20) ลุกยืน และปรับท่านั่ง
ไม่ส่งข้อมูลออกอินเทอร์เน็ต ไม่มีบัญชี ไม่เก็บข้อมูลส่วนตัว (อ่าน PRIVACY.md)
ใช้ได้กับ Windows 10 และ Windows 11 ฟรี ไม่ต้องปิดระบบความปลอดภัยใดๆ ของ Windows

ชุดนี้ไม่มีไฟล์ .exe ของเรา โปรแกรมทำงานผ่าน Python ตัวจริงจาก Python Software Foundation
(จึงใช้ได้แม้เปิด Smart App Control ใน Windows 11)

วิธีติดตั้ง (ทำครั้งเดียว)
1. คลิกขวาไฟล์ zip > Extract All (แตกไฟล์ทั้งหมด) อย่าเปิดจากในไฟล์ zip โดยตรง
2. ดับเบิลคลิกไฟล์  INSTALL.bat
   (ถ้า Windows ขึ้นเตือน "Windows protected your PC" ให้กด More info > Run anyway)
3. ถ้าเครื่องยังไม่มี Python โปรแกรมจะติดตั้งให้เองผ่าน winget (ใช้เวลาสักครู่ ต้องมีอินเทอร์เน็ต)
   - ถ้า Windows ถามอนุญาต ให้กด Yes
   - ถ้ามีโปรแกรมแอนตี้ไวรัสอื่นในเครื่อง (เช่น 360 Total Security) แล้วขึ้นหน้าต่างเตือน
     ให้กด "Allow / อนุญาต" ให้ทัน (มีนับถอยหลังประมาณ 10 วินาที ถ้าไม่ทันมันจะบล็อกเอง)
     และอย่าติ๊ก "ไม่ต้องเตือนอีก" ไว้
   - ติดตั้ง Python เสร็จแล้วถ้าหน้าต่างให้ปิด ให้ปิดแล้วดับเบิลคลิก INSTALL.bat อีกครั้ง
4. ตอบ Y เมื่อถามว่าจะให้เปิดอัตโนมัติตอนเข้า Windows หรือไม่ (ถ้าต้องการ)
5. มองหาไอคอนที่มุมขวาล่างของจอ (ถาดระบบ อาจอยู่ใต้ลูกศร ^ )
   เปิดอีกครั้งได้จากเมนู Start > "ผู้ช่วยสุขภาพดิจิทัล"

ถอนการติดตั้ง: ดับเบิลคลิก UNINSTALL.bat (ใน zip หรือในโฟลเดอร์ติดตั้ง)
โปรแกรมติดตั้งที่  %LOCALAPPDATA%\DigitalWellnessAssistant-Source
(การตั้งค่าและบันทึกเก็บในโฟลเดอร์เดียวกัน ตอนถอนจะถามว่าจะลบด้วยหรือไม่)

ถ้าติดตั้งไม่สำเร็จ
- ขึ้นว่าหา Python ไม่เจอ: ปิดหน้าต่าง แล้วดับเบิลคลิก INSTALL.bat ใหม่อีกครั้ง
  (ครั้งที่สองมักผ่าน) ถ้ายังไม่ผ่าน ให้ถ่ายภาพหน้าจอทั้งหน้าต่างส่งให้ผู้ที่ส่งไฟล์นี้ให้คุณ
- Windows หรือแอนตี้ไวรัสขึ้นหน้าต่างเตือนอื่นๆ: หยุดก่อน แล้วส่งภาพหน้าจอให้ผู้ส่งไฟล์
